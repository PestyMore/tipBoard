# tipBoard

一个使用 Rust 和 egui 构建的简洁、轻量、且永远置顶的备忘小工具。

## ✨ 功能特性
- 永远置顶：窗口悬浮在所有应用之上
- 阅读 & 编辑双模式：干净阅读视图 + 强大编辑视图
- 拖拽排序：轻松调整分区和条目顺序
- 高度可配置：窗口大小、字体、图标集中在配置文件中
- 绿色便携：单一 `.exe` 文件，无需安装，数据自动保存
